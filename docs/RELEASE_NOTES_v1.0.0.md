# Jungle NFT Marketplace v1.0.0

Primeira versão completa do Frontend Challenge: experiência fiel ao universo
visual do Figma, responsiva e preparada para avaliação funcional.

## Destaques

- Fluxo do catálogo ao recibo, conta e carteiras.
- Mock REST resiliente e Socket.IO verdadeiro sobre MSW.
- Pedidos idempotentes, recuperação de timeout e cotação revalidada.
- Playwright desktop/mobile, regressão visual e Lighthouse CI.
- SEO/WhatsApp banner, acessibilidade e deploy Netlify com headers de segurança.

## Teste rápido

Use `ada@jungle.test` / `Jungle@123`, adicione um NFT e aplique `JUNGLE10`.
O laboratório de cenários permite observar falhas e eventos em tempo real.

Consulte `CHANGELOG.md`, `ARCHITECTURE.md` e o bloco de deploy no `README.md`.
